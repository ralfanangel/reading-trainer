# reading-trainer

Initial repository commit. This repo will contain an iPad-first SwiftUI app (with a macOS Catalyst target for testing) that teaches reading to kids ages 4–8.

This initial commit creates a minimal scaffold in a new branch `scaffold/initial-swiftui` with a small SwiftUI app skeleton (Profile, basic animals game placeholder) that uses AVSpeechSynthesizer for on-device TTS.

Next steps:
- Create a feature branch and add Swift source files for the basic app skeleton.
- Expand the scaffold: avatar placeholder, asset pipeline, offline content loading from a local Synology server.

I'll now create the feature branch and push the initial SwiftUI scaffold files into it.
